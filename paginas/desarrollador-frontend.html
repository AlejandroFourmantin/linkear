Desarrollador Frontend

En Linkear nos encontramos en la búsqueda de un/a Desarrollador/a Frontend con experiencia sólida en tecnologías modernas para integrarse a un equipo dinámico, colaborativo y con proyectos de alto impacto.

Modalidad: Híbrida / Remota
Jornada: Lunes a Viernes

Principales Responsabilidades

  • Desarrollar e implementar interfaces de usuario web responsivas, intuitivas y de alto rendimiento.
  • Trabajar mano a mano con diseñadores UI/UX y el equipo backend para conectar servicios y APIs.
  • Mantener y optimizar aplicaciones existentes garantizando código limpio, modular y testeable.
  • Proponer mejoras de arquitectura, buenas prácticas y nuevas herramientas de desarrollo.

Requisitos y Habilidades

  • Experiencia comprobable trabajando con HTML5 semántico, CSS3 moderno y JavaScript/TypeScript.
  • Dominio de React (Hooks, Context API, state management) y frameworks de diseño como Tailwind CSS o Bootstrap.
  • Conocimientos de control de versiones con Git y flujos de trabajo colaborativos (GitHub/GitLab).
  • Capacidad de comunicación efectiva, proactividad y orientación a resultados.

Qué Ofrecemos

  • Remuneración competitiva acorde al mercado y revisiones periódicas.
  • Flexibilidad horaria y excelente clima de trabajo centrado en las personas.
  • Oportunidades reales de crecimiento profesional y capacitaciones continuas.
